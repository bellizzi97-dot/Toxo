# Toxo offline assistant

This project is structured as a practical starter for an offline AI assistant.

## Dependencies

The core backend runs with the Python standard library only.

Optional model runtime:

- ollama

## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Optional runtime

If Ollama is installed on the machine, Toxo can call a local model automatically:

```bash
ollama pull llama3.2
```

This keeps responses local and offline.
